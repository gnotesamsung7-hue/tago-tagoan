# Matthew and Xian’s Tago Tagoan

First-person hide-and-seek horror game for Android.

Every push builds the APK with GitHub Actions. Get it from the **Releases** section on the right side of this page and open `TagoTagoan.apk` on your phone.

To update the game, replace `app/src/main/assets/index.html` and commit — a new APK is built automatically.
